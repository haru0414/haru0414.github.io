ADMIN SYSTEM ARC — 2024 | Haru Li

DETAIL

問題

接手既有的後台管理系統，需要在不中斷營運的前提下維護多個業務核心模組。其中客服聊天室必須即時收發訊息，並處理 LINE 送來的各種事件型別。

做法

以 React / Next.js / TypeScript / MUI 接手並維護。客服聊天室用 WebSocket 實現即時訊息推播，支援 LINE 貼圖渲染、快速回覆範本與多媒體檔案上傳，並處理多種 webhook 事件分發。另維護排班系統、訂單管理、商家後台、會員管理與折扣活動等多個業務核心頁面。

結果

支撐千萬級年營業額新創公司的日常營運。
